# module2pythonassessment2
ABC Company Employee Data Analysis

Project Overview

This project analyzes employee data from ABC Company using Python. It focuses on data preprocessing, employee distribution, age-group analysis, salary expenditure, and the relationship between age and salary.

Tools and Libraries

Python

Pandas

NumPy

Matplotlib

Seaborn

Data Preprocessing

The height column was replaced with randomly generated integers between 150 and 180. The dataset was inspected for missing values, and the salary column was converted to a numeric data type for analysis.

Analysis Performed

Employee distribution across teams, including percentage split.

Employee distribution across positions.

Identification of the predominant age group.

Salary expenditure by team and position.

Correlation between employee age and salary.

Visualizations

Bar charts, count plots, scatter plot and a heatmap were created to communicate the findings.

Key Findings

The notebook presents the team with the highest employee count, the most common position, the predominant age group, the teams and positions with the highest recorded salary expenditure, and the correlation between age and salary.
